    What you're watching. Every few hours a GitHub Actions bot wakes up, draws random patches of sky away from the Milky Way, and picks sun-like and red-dwarf stars that NASA's TESS satellite photographed. For each one it downloads the brightness measurements from NASA's MAST archive, removes the star's own flickering, tests tens of thousands of possible orbital periods for a repeating dip, runs the same red-flag checks astronomers use, scores the signal with a machine-learning model, and checks every public catalog (TOIs, community TOIs, confirmed planets, known eclipsing binaries) to see if it is already known. Stars are never searched twice. The bot pushes progress here every ~15 minutes while it runs.
